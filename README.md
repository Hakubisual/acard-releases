# Acard desktop downloads

Public installers of the Acard desktop app. Get the current version at **https://acard.dev/download**.

- Windows: `Acard-<version>-win-x64.exe` (installer). The app updates itself from https://acard.dev/releases/win/latest.yml.
- macOS: `Acard-<version>-mac-arm64.dmg` (Apple Silicon) and `Acard-<version>-mac-x64.dmg` (Intel).

The installers are not code-signed yet. On Windows click **More info > Run anyway**; on macOS open the app once, then
**System Settings > Privacy & Security > Open Anyway**. Your notes stay in your own data folder and are never removed by
an update or an uninstall.

Source of the open edition: https://github.com/Hakubisual/open-notion
